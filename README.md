# Zomato Restaurant Analysis

## Overview
End-to-end analysis of 19,258 Zomato restaurants across 140 cities
to identify cuisine trends, city-wise performance, rating patterns,
and pricing insights.

## Tools Used
- SQL (MySQL) — 2 case studies with 36 queries
- Excel (Power Query) — data cleaning and dashboard
- Power BI — interactive analytics dashboard
- Tableau — visualization dashboard

## Key KPIs Tracked
- Total Restaurants: 19,258
- Total Cities: 140
- Average Rating: 3.04
- Online Delivery %: 29.29%

## Key Insights
- North Indian and Chinese cuisines are most popular
- New Delhi has the highest restaurant count (8,230)
- Most restaurants fall in the 3–3.99 rating range
- Higher cost does not always mean higher rating
- ~29% of restaurants offer online delivery

## Project Workflow
1. Data Understanding
2. Data Cleaning & Transformation (Excel Power Query)
3. KPI Identification
4. Visualization & Dashboarding (Excel, Power BI, Tableau)
5. Business Insights & Recommendations
6. MySQL Case Studies for structured data analysis
